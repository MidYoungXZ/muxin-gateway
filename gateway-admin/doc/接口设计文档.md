# Muxin Gateway API 接口设计文档

## 1. 概述

### 1.1 API 设计规范
- 遵循 RESTful 风格
- 统一的 URL 命名规范
- 统一的响应格式
- 完善的错误处理
- API 版本管理

### 1.2 基础 URL
```
开发环境: http://localhost:8080/api
生产环境: /api
```

### 1.3 认证方式
- 使用 Sa-Token 进行认证
- 请求头携带 Token: `satoken: <token>`
- 登录和注册接口无需认证

### 1.4 统一响应格式

#### 成功响应
```json
{
  "code": 200,
  "message": "success",
  "data": {},
  "timestamp": 1704985200000
}
```

#### 失败响应
```json
{
  "code": 400,
  "message": "错误信息描述",
  "data": null,
  "timestamp": 1704985200000
}
```

### 1.5 响应码说明
| 响应码 | 说明 |
|--------|------|
| 200 | 成功 |
| 400 | 请求参数错误 |
| 401 | 未认证 |
| 403 | 无权限 |
| 404 | 资源不存在 |
| 500 | 服务器内部错误 |

## 3. 路由管理接口

### 3.1 获取路由列表

**接口地址**: `GET /api/routes`

**请求参数**:
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| page | int | 否 | 页码，默认1 |
| size | int | 否 | 每页数量，默认10 |
| keyword | string | 否 | 搜索关键字 |
| enabled | boolean | 否 | 是否启用 |

**请求示例**:
```
GET /api/routes?page=1&size=10&enabled=true
```

**响应数据**:
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "total": 100,
    "list": [
      {
        "id": 1,
        "routeId": "user-service",
        "routeName": "用户服务",
        "description": "用户服务路由",
        "uri": "lb://user-service",
        "predicates": [...],
        "filters": [...],
        "metadata": {...},
        "order": 1,
        "enabled": true,
        "createTime": "2024-01-01 00:00:00",
        "updateTime": "2024-01-01 00:00:00"
      }
    ]
  }
}
```

**状态码**:
- 200: 成功

---

### 3.2 创建路由

**接口地址**: `POST /api/routes`

**请求头**: `satoken: <token>`

**请求参数**:
```json
{
  "routeId": "string",
  "routeName": "string",
  "description": "string",
  "uri": "string",
  "predicates": [
    {
      "type": "PATH",
      "config": {
        "pattern": "/api/users/**"
      }
    }
  ],
  "filters": [
    {
      "type": "AUTH",
      "config": {
        "authType": "JWT",
        "secretKey": "your-secret"
      }
    }
  ],
  "metadata": {},
  "order": 0,
  "enabled": true
}
```

**响应数据**:
```json
{
  "code": 200,
  "message": "创建成功",
  "data": {
    "id": 1
  }
}
```

**状态码**:
- 200: 创建成功
- 400: 参数错误
- 409: 路由ID已存在
