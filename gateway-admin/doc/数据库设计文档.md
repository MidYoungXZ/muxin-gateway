# Muxin Gateway 数据库设计文档

## 1. 概述

### 1.1 数据库技术选型
- **数据库**: MySQL 8.0
- **字符集**: utf8mb4
- **存储引擎**: InnoDB
- **ORM框架**: MyBatis-Flex 3.9.8

### 1.2 数据库设计原则
- 遵循第三范式，减少数据冗余
- 合理使用索引，优化查询性能
- 支持逻辑删除，便于数据恢复
- 使用审计字段，记录数据变更
- 统一命名规范，便于维护

### 1.3 命名规范

| 类型 | 规范 | 示例 |
|------|------|------|
| 表名 | 小写+下划线 | `sys_user` |
| 字段名 | 小写+下划线 | `user_name` |
| 主键 | `id` | `id` |
| 外键 | `相关表_id` | `user_id` |
| 索引 | `idx_字段名` | `idx_username` |
| 唯一索引 | `uk_字段名` | `uk_route_id` |
| 删除标记 | `deleted` | 0-正常，1-删除 |

## 2. 数据库表设计

### 2.1 用户管理相关表

#### 2.1.1 sys_user（用户表）

**表说明**: 存储系统用户信息

```sql
CREATE TABLE `sys_user` (
  `id` bigint NOT NULL AUTO_INCREMENT COMMENT '用户ID',
  `username` varchar(50) NOT NULL COMMENT '用户名',
  `password` varchar(100) NOT NULL COMMENT '密码（BCrypt加密）',
  `nickname` varchar(50) DEFAULT NULL COMMENT '昵称',
  `email` varchar(100) DEFAULT NULL COMMENT '邮箱',
  `phone` varchar(20) DEFAULT NULL COMMENT '手机号',
  `avatar` varchar(500) DEFAULT NULL COMMENT '头像URL',
  `status` tinyint DEFAULT '1' COMMENT '状态：0-禁用，1-正常',
  `create_time` datetime DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `update_time` datetime DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  `deleted` tinyint DEFAULT '0' COMMENT '删除标记：0-否，1-是',
  PRIMARY KEY (`id`),
  UNIQUE KEY `idx_username` (`username`),
  KEY `idx_email` (`email`),
  KEY `idx_phone` (`phone`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='用户表';
```

**字段说明**:
| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | bigint | 主键ID，自增 |
| username | varchar(50) | 用户名，唯一索引 |
| password | varchar(100) | 密码，BCrypt加密存储 |
| nickname | varchar(50) | 昵称 |
| email | varchar(100) | 邮箱 |
| phone | varchar(20) | 手机号 |
| avatar | varchar(500) | 头像URL |
| status | tinyint | 状态：0-禁用，1-正常 |
| create_time | datetime | 创建时间 |
| update_time | datetime | 更新时间 |
| deleted | tinyint | 逻辑删除标记：0-否，1-是 |

### 2.2 网关配置相关表

#### 2.2.1 gw_route（路由配置表）

**表说明**: 存储网关路由配置信息

```sql
CREATE TABLE `gw_route` (
    `id` BIGINT NOT NULL AUTO_INCREMENT COMMENT '主键ID',
    `route_id` VARCHAR(100) NOT NULL COMMENT '路由ID（唯一标识）',
    `route_name` VARCHAR(100) NOT NULL COMMENT '路由名称',
    `description` VARCHAR(500) DEFAULT NULL COMMENT '路由描述',
    `uri` VARCHAR(500) NOT NULL COMMENT '目标URI',
    `predicates` JSON DEFAULT NULL COMMENT '断言配置（JSON格式）',
    `filters` JSON DEFAULT NULL COMMENT '过滤器配置（JSON格式）',
    `metadata` JSON DEFAULT NULL COMMENT '元数据（JSON格式）',
    `order` INT NOT NULL DEFAULT 0 COMMENT '路由顺序（值越小优先级越高）',
    `enabled` TINYINT NOT NULL DEFAULT 1 COMMENT '是否启用：0-禁用，1-启用',
    `create_time` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    `update_time` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    `create_by` VARCHAR(50) DEFAULT NULL COMMENT '创建人',
    `update_by` VARCHAR(50) DEFAULT NULL COMMENT '更新人',
    `deleted` TINYINT NOT NULL DEFAULT 0 COMMENT '是否删除：0-否，1-是',
    PRIMARY KEY (`id`),
    UNIQUE KEY `uk_route_id` (`route_id`),
    KEY `idx_enabled` (`enabled`),
    KEY `idx_order` (`order`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='网关路由表';
```

| route_name | VARCHAR(100) | 路由名称 |

| predicates | JSON | 断言配置，JSON格式 |

## 4. 索引设计

### 4.1 主键索引
所有表均使用自增主键 `id`，采用 `BIGINT` 类型，支持大量数据。

### 4.2 唯一索引
| 表名 | 索引名 | 字段 |
|------|--------|------|
| sys_user | idx_username | username |
| sys_role | idx_role_code | role_code |
| gw_route | uk_route_id | route_id |
| gw_route_filter | uk_route_filter | (route_id, filter_id) |
| gw_route_predicate | uk_route_predicate | (route_id, predicate_id) |
| gw_load_balance | uk_route_id | route_id |

### 4.3 普通索引
| 表名 | 索引名 | 字段 |
|------|--------|------|
| sys_user | idx_email | email |
| sys_user | idx_phone | phone |
| sys_menu | idx_parent_id | parent_id |
| sys_menu | idx_status | status |
| gw_route | idx_enabled | enabled |
