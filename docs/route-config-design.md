# 路由配置页面交互设计文档

## 1. 设计概述

### 1.1 设计目标

重新设计路由配置页面的交互流程，参考 APISIX Dashboard 的设计理念，提供清晰、直观、易用的配置体验。

### 1.2 核心设计决策

| 决策项 | 选择 | 说明 |
|--------|------|------|
| 配置流程 | 四步向导式 | 基本信息 → 路由匹配 → 目标服务 → 插件配置 |
| 步骤导航位置 | 左侧 | 固定在对话框左侧，方便随时切换 |
| 插件类型 | AUTH + FILTER | 移除 MATCH 类型，路由匹配由断言器完成 |
| 表单校验 | 仅必填项 | 暂时只校验必填字段，简化交互 |
| 插件交互 | 选择即配置 | 点击插件立即打开配置抽屉 |
| 执行可视化 | 优先级列表 | 列表展示插件及优先级，自动排序 |

```typescript
interface RouteFormState {
  // Step 1: 基本信息
  routeId: string
  routeName: string

  plugins: RoutePlugin[]
}

interface HeaderMatch {
  name: string
  value: string
  matchType: 'EXIST' | 'NOT_EXIST' | 'EQUAL' | 'REGEX'
}

interface QueryMatch {
  name: string
  value: string
  matchType: 'EXIST' | 'NOT_EXIST' | 'EQUAL' | 'REGEX'
}

interface RoutePlugin {
  pluginId: number
  pluginName: string
  pluginType: 'AUTH' | 'FILTER'
  config: Record<string, any>
  priorityOverride?: number
  enabled: boolean
}
```

```
                       →    PredicateDefinition {
                             name: "Host",
                             args: {
                               patterns: ["api.example.com"]
                             }
                           }
```

### 12.2 插件配置转换为 FilterDefinition

Step 4 的插件配置转换为 FilterDefinition：

```
前端配置                   后端转换
─────────────────────────────────────────────────────────────
jwt-auth              →    JwtAuthGatewayFilter
                       →    FilterDefinition {
                             name: "JwtAuth",
                             order: 8000,
                             args: {
                               secret: "xxx",
                               header: "Authorization"
                             }
                           }

rate-limit            →    RateLimitGatewayFilter
                       →    FilterDefinition {
                             name: "RateLimit",
                             order: 6000,
                             args: {
                               rate: 100,
                               key: "remote_addr"
                             }
                           }
```
