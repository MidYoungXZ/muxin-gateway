## MODIFIED Requirements

### Requirement: 路由详情页面必须正确显示所有配置信息
路由详情对话框必须正确显示断言配置和插件配置的详细参数，数据绑定必须与后端返回的数据结构一致。

#### Scenario: 断言配置列显示正确的参数数据
- **WHEN** 用户查看路由详情
- **THEN** 断言配置表格的"配置"列必须正确显示 `args` 字段的内容，而非 `config` 字段

#### Scenario: 插件配置列显示正确的配置数据
- **WHEN** 用户查看路由详情
- **THEN** 插件配置表格的"配置"列必须正确显示 `config` 字段的内容

### Requirement: 路由详情页面必须使用美观清晰的布局
路由详情对话框应使用卡片式布局分组展示不同类型的信息，提升信息层次感和可读性。

#### Scenario: 使用卡片分组展示信息
- **WHEN** 用户查看路由详情
- **THEN** 页面应分为基本信息、断言配置、插件配置三个卡片区域

#### Scenario: 使用标签和图标增强视觉识别
- **WHEN** 显示状态、类型等字段
- **THEN** 应使用 el-tag 标签和适当的颜色区分不同状态和类型

#### Scenario: JSON 配置使用美观的代码块样式
- **WHEN** 显示配置参数（JSON 格式）
- **THEN** 应使用带背景色、边框、圆角的代码块样式，并使用等宽字体

### Requirement: 路由详情页面必须支持暗黑模式
所有自定义样式必须兼容 Element Plus 的暗黑模式，使用 CSS 变量而非硬编码颜色值。

#### Scenario: 亮色主题下显示正常
- **WHEN** 用户使用亮色主题
- **THEN** 所有元素应使用适当的浅色背景和深色文字

#### Scenario: 暗色主题下显示正常
- **WHEN** 用户使用暗色主题
- **THEN** 所有元素应自动适配暗色背景和浅色文字
