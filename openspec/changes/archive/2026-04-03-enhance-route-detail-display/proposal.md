## 背景

当前路由详情页面存在两个主要问题：
1. 断言配置和插件配置的"配置"列数据展示缺失，前端使用了错误的字段名（args vs config）
2. 详情页面整体布局简陋、配色单一，缺乏层次感和视觉美观，用户体验不佳

这些问题会导致用户无法正确查看路由的详细配置信息，影响网关管理系统的可用性。需要修复数据显示错误并优化整体展示效果。

## 变更内容

- 修复断言配置列表格中配置列的数据绑定错误（row.config → row.args）
- 优化配置列的 JSON 展示格式，使用更美观的代码块样式
- 重新设计路由详情对话框的布局结构，使用卡片式分组
- 优化配色方案，提升视觉层次感
- 添加断言和插件的状态标签（启用/禁用）
- 改善空白状态的处理和提示
- 使用更合理的字段标签和格式化显示

## Capabilities

### Modified Capabilities

- `admin-ui`: 优化路由详情页面的数据展示和视觉设计，提升用户体验

## Impact

- 受影响文件：
  - gateway-admin-ui/src/views/routes/list/index.vue（路由详情对话框）
  - gateway-admin-ui/src/api/routes.ts（可能需要调整 TypeScript 接口定义）
- 前端层面：仅修改展示层代码，不涉及 API 变更
- 用户体验：正面影响，提升信息可读性和视觉美观度
- 破坏性变更：无
